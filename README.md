# CertGen Pro — Email Backend
Sends real PDF certificates via Gmail SMTP.

## Setup on Render
1. Push this folder to GitHub
2. render.com → New Web Service → connect repo
3. Add env vars:
   - GMAIL_USER = ytkesavan77@gmail.com
   - GMAIL_APP_PASSWORD = (16-char App Password from Google Account → Security → App Passwords)
4. Deploy → copy your URL
